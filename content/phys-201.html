Printing variables inside text in Python

You will learn three ways to mix variables and text in print(), why the first two sometimes break, and why f-strings are usually the best choice. Type each example yourself and run it.

1. Printing several items with a comma

print() can take many items at once. Separate them with commas and Python prints them on one line. 

name = "Aisha"
print("Hello", name)
Hello Aisha

Notice that a space appeared between Hello and Aisha, even though we never typed one. The comma adds a single space between items automatically.

Commas also accept numbers, with no extra work:

age = 12
print("Age:", age)
Age: 12

2. Joining text with +

The + operator can also build a message. With text, it glues the pieces together (this is called concatenation). 

name = "Aisha"
print("Hello " + name)
Hello Aisha

It worked, but look closely: there is a space inside the quotes after Hello. We had to type it ourselves.

3. The difference: spaces

Comma adds a space for you. Plus adds nothing. Here is what happens if we forget the space with +: 

print("Hello" + name)
HelloAisha

That looks like a bug, but sometimes it is exactly what you want. When you need no space, the comma cannot help you, because it always adds one: 

price = "5"
print("$", price)     # comma puts a space in
print("$" + price)    # plus keeps them together
$ 5
$5

4. The problem: adding a number and text with +

Every value in Python has a data type. "12" in quotes is a string (str), which is text. 12 without quotes is an integer (int), which is a number you can do maths with.

The + operator means two different things depending on the types. Between two numbers it adds them. Between two strings it joins them. But Python refuses to guess what you mean when you mix the two. 

age = 12
print("I am " + age + " years old")
TypeError: can only concatenate str (not "int") to str

Python is saying: “I can only join text to text, and age is a number.” The same thing happens the other way around: 

print(5 + "5")
TypeError: unsupported operand type(s) for +: 'int' and 'str'

Should 5 + "5" be 10 or "55"? Both are reasonable answers, so Python raises an error instead of choosing for you.

5. The fix: str() and int()

You can convert a value from one type to another. The conversion is temporary: it makes a new value for that one place and leaves the original variable unchanged.

str() turns a number into text:

age = 12
print("I am " + str(age) + " years old")
print(type(age))     # still an int
I am 12 years old
<class 'int'>

int() turns text that looks like a number into a real number: 

total = "5"
print(5 + int(total))
10

Remember: input() always gives you a string, even if the user types digits. Use int() on it before doing maths.

6. Why matching types matters with +

The rule is simple: both sides of + must be the same type. And the type you choose decides the result: 

a = "5"
b = "5"
print(a + b)             # text + text: joined
print(int(a) + int(b))   # number + number: added
55
10

Same digits, completely different answers. That is why you must always ask: “Do I want to join text, or do maths?” Then convert so that both sides match. 

print("5" + 5)           # str + int: error
print("5" + str(5))      # str + str: "55"
print(int("5") + 5)      # int + int: 10
(first line fails with TypeError)
55
10

Also be careful: int() only works on text that is really a whole number. int("hello") raises a ValueError.

7. A better way: f-strings

All that converting and spacing gets tiring. Python has a cleaner way: put an f directly before the opening quote, and write variables inside { } curly braces. 

name = "Aisha"
age = 12
print(f"Hello {name}, I am {age} years old")
Hello Aisha, I am 12 years old

Compare it with the + version of the same sentence:

print("Hello " + name + ", I am " + str(age) + " years old")   # long and easy to get wrong
print(f"Hello {name}, I am {age} years old")                    # short and readable

Here is how f-strings solve each problem from earlier:

  • Spaces: you control them exactly, because what you type is what you get. Need no space? f"${price}" gives $5.
  • Types: numbers go straight in. No str() needed, and no TypeError.
  • Readability: the sentence reads like a sentence, not a chain of pieces.

You can even do maths or call functions inside the braces:

apples = 3
price = 2.5
print(f"{apples} apples cost {apples * price} dollars")
print(f"Shouting: {name.upper()}!")
3 apples cost 7.5 dollars
Shouting: AISHA!

One bonus: format numbers neatly with :.2f for two decimal places. 

cost = 7.5
print(f"Total: ${cost:.2f}")
Total: $7.50

Don’t forget the f. Without it, Python prints the braces literally: print("Hello {name}") shows Hello {name}.

8. Recap

Method Space Numbers Use it when
print("a", b) Automatic Fine Quick output
"a" + b You add it Needs str() Joining strings with no gap
f"a {b}" You add it Fine Most of the time

Rule of thumb: use f-strings by default. Use + when you are deliberately joining strings, and make sure the types match.
